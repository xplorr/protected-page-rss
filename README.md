# protected-page-rss
This repository generates RSS feeds daily from protected webpages using Browserless.

After GitHub Pages is enabled, the generated files will be available at:

- `https://YOUR_USERNAME.github.io/protected-page-rss/`
- `https://YOUR_USERNAME.github.io/protected-page-rss/feed1.xml`
- `https://YOUR_USERNAME.github.io/protected-page-rss/index1.html`

If more URLs are added, more files will be generated:

- `feed2.xml`
- `index2.html`
- etc.
